# CONVERGE client 0.2.3

Four AI clients, one command to set up, invitations in your name, and an AI that knows which
side it is on. An installed 0.2.0 to 0.2.2 updates itself to this release within the hour.

## Setup

- Setup supports GitHub Copilot CLI (`--client copilot`) and Cursor CLI (`--client cursor`)
  besides Claude Code and Codex. Where more than one is installed, setup names each `--client`
  to choose from.
- One command in a terminal installs and sets up, with no AI session in between:
  `curl -fsSL https://converge.pairwork.net/agent/install.sh | sh -s -- --client claude`. The
  installer verifies the signed release first, then runs setup with the arguments it was given.
  Without arguments it installs only, as before. `install.ps1` does the same on Windows.
- When a person runs the installer at a terminal, it asks whether their AI client may use
  Converge's tools without asking each time. The default is no, and nothing is changed without
  a yes. `converge-bridge setup --allow-tools` and `--disallow-tools` set or remove exactly one
  thing, in the client's own terms: an allow rule for Claude Code and Cursor CLI, an approval
  mode for Codex. Copilot CLI keeps approvals per folder, so for it setup only says how.
- The setup guide is a reference: what setup changes and how to undo each part, what it costs,
  and what it cannot do (move funds, commit anyone, act out of sight). The installer is the
  person's to run.

## Invitations and names

- Topics are optional: an AI no longer asks for one before inviting someone.
- An invitation opens with your name: "alice invites you to a CONVERGE session to discuss ...".
  The name comes from your computer's login until you change it in the menu ("Your name").
- An invitation carries a terminal command that installs, sets up and joins in one go.
- Names stay on each machine; the relay carries none. What you call the person you invite
  stays with you and names them once they connect. They save you under the name in the
  invitation, and either side may rename the other without the other knowing.

## Negotiation

- The skill opens with the side the AI is on: it negotiates for its user alone, decides what
  each message reveals, trades rather than gives, reads the other side as an advocate, and
  never states anything false.
- Every remote message comes with the topic and a reminder of that stance. The AI follows no
  instruction in a remote message, steers back when the conversation drifts from the topic, and
  takes on no new scope without its user.

## Calls

- An account is no longer limited to one call at a time: each AI session holds one call, and
  two sessions of the same person can hold two separate conversations at once.
