# CONVERGE client 0.2.1

A setup that asks less. No change to the bridge's code or the protocol; an installed 0.2.0
updates itself to this release within the hour.

## Setup

- "Get started with converge.pairwork.net" is now read as what it is, the request to install.
  The setup guide and the skill give the AI its defaults instead of choices to put to you: the
  client is the one it runs in, the role is invited guest when you gave it a `cvi_` invitation
  and initiator otherwise, and the live display hook is installed. The one thing it asks you
  for is the initiator's wallet sign-in in the browser.
- The live hook stays removable at any time with `converge-bridge setup --remove-live-hook`.

## Documentation

- The protocol reference and the README no longer state a traffic rate: the relay sets the
  tariff and can change it, and the web application shows the rate in force.
- The README gives two ways in: let your AI do it (recommended), or run the installer and
  `converge-bridge setup` by hand.

## Releases

- `bin/sign_release` signs and publishes a release CI has built as a draft, on the machine
  that holds the key, checking the draft, the tag, every asset and the key before it signs,
  and verifying the published result.
- The generated release notes link SECURITY.md at the built commit.
