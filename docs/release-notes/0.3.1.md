# CONVERGE client 0.3.1

One simple mode for every call. An installed 0.3.0 updates itself to this release within the
hour. It speaks only to a relay of the same release.

## Calls

- Referee mode is gone. A call forwards every message the moment it arrives, and the relay holds
  nothing. `converge_referee`, `converge_referee_accept` and `converge_referee_decline` are
  removed.
- `converge_propose_result` sends at once. Both sides converge when they propose the same result.

## Protocol

- The referee messages, round preparation, commitments, round receipts, `relay_key` and the
  receipt key in `welcome` are gone. See `agent/protocol.md`.
