# CONVERGE client 0.3.5

The hook that keeps a conversation going reaches installations made before it existed. An
installed 0.3.3 or 0.3.4 updates itself to this release within the hour, and it speaks to the
relay as it is today.

## The hook, without running setup again

- Release 0.3.4 added a hook that keeps your AI's turn open while the other side is to write, and
  carries it on when their message arrives. Until now an installation made before 0.3.4 only got
  it by running `converge-bridge setup` again.
- Now the first time CONVERGE starts after the update, it registers that hook itself, in Claude
  Code and Codex, and the next CONVERGE banner tells you so. It takes effect in your next AI
  session. Codex asks you to review it first (`/hooks`).
- It does this only where setup had registered CONVERGE's other hook and it is still there. If
  you set CONVERGE up without hooks, or removed them, nothing is added, and a hook you take out
  afterwards is not put back.
- To remove CONVERGE's hooks: `converge-bridge setup --remove-live-hook`.
